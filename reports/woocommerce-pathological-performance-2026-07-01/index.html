Fixture and Caveats

Dataset1000000 HPOS orders, 200000 simple products, 800 variations on one variable productStackWordPress 7.0, WooCommerce 10.9.1, PHP 8.3.31
MethodSerial curl samples plus targeted concurrent curl fan-outs against one Docker site with SAVEQUERIES; reports include PHP wall time, query count, DB time, peak memory, and slow SQL excerpts.InterpretationGood for code-path shape and relative local pressure. Not a replacement for production RUM, k6 load curves, or multi-node database contention testing.
